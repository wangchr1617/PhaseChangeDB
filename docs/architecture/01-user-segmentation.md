- **日期**：2026-09-19

## 1. 用户分类与矩阵定位

PhaseChangeDB 并非通用娱乐型聊天工具或开放域百科，而是**面向相变材料领域、以严密实验证据为基石的科学数据库与知识发现平台**。

| 用户层级 | 目标角色 | 典型组织/背景 | 核心关注点 | 服务轮次 |
| :--- | :--- | :--- | :--- | :--- |
| **核心用户 (P0)** | **相变存储实验科学家** | 高校、中科院材料研究所、微电子国家重点实验室 | 升温速率条件对齐、相变物理参数可比性、原始图表文献回溯 | **第一轮已服务，第二轮深度增强** |
| **核心用户 (P0)** | **AI4Science / 计算材料学者** | 材料基因组团队、计算物理与机器学习研发组 | 结构化高质量物性数据集、标准化 API、化学空间拓扑关联 | **第二轮重点支持** |
| **核心用户 (P0)** | **领域数据审核专家 (Curator)** | 课题组学术骨干、专职科学数据审核编辑 | AI 提取候选判定、争议文献仲裁、不可逆撤回追溯 | **第一轮打通，第二轮效率强化** |
| **次要用户 (P1)** | **相变器件与芯片研发工程师** | 半导体晶圆厂、存储芯片企业 (PCRAM/存算一体) | 器件翻转时间（$t_{\text{SET}}$）、器件耐久性与高低阻态阻值窗口 | **第三轮演进** |
| **管理/运维 (P1)** | **系统运维与安全管理员** | IT 运维团队、科研数据库维护人员 | 密钥安全、多角色访问控制、备份与系统稳定性 | **第二轮安全整改** |
| **生态合作 (P2)** | **开源开发者与学术贡献者** | 计算机与材料信息学交叉学科开发者 | 模块化解耦、插件式解析器、规范的贡献契约 | **第二轮架构治理支持** |
| **非目标用户 (Excluded)** | **通用聊天机器人爱好者 / 业余写手** | 寻求常识生成、无证据要求的问答 | 开放式聊天生成、无科学证据支撑的文本臆测 | **明确不予服务** |

## 2. 核心用户画像与典型使用场景

### 用户画像 1：相变动力学实验学者 —— 李研究员 (Dr. Li)
- **背景**：中科院上海硅酸盐所副研究员，主要从事掺杂 GeTe 与 Sb2Te3 薄膜材料的非等温结晶动力学研究。
- **典型场景**：
  1. 正在探索提高 GeTe 结晶温度 $T_c$（目前约为 180°C）以满足汽车级高温数据保持规范。
  2. 调研文献中通过不同元素（Ti, Sc, Bi, N）掺杂对结晶温度和活化能 $E_a$ 的调控规律。
  3. 打开 PhaseChangeDB 的【跨文献物性横向对比看板】，按升温速率（10, 20, 40 K/min）对齐过滤，查看箱线图与散点分布。
  4. 点击异常散点，右侧滑出文献证据抽屉，直击原始文献中 `Figure 3(b)` 与正文测定描述，确认测试方法为非等温电阻-温度（R-T）测试。
- **核心痛点**：
  - 各篇文献升温速率各异，脱离升温速率直接对比数值导致误判；
  - 手工换算单位（$\text{eV} \leftrightarrow \text{kJ/mol}$）容易出现数量级错误；
  - 传统大模型提取常常出现“张冠李戴”的幻觉，无法复核出处。
- **需求优先级**：
  - P0：实验条件（升温速率、膜厚）严格对齐；
  - P0：单位自动无损归一化（保留原始单位）；
  - P0：原文证据片段与图表标注无缝穿透；
  - P1：对比数据与图表一键导出为 CSV/Excel/Origin 格式。

### 用户画像 2：AI4Science 算法研究员 —— 张博士 (Dr. Zhang)
- **背景**：某高校材料基因工程团队博士后，致力于相变材料新成分与性能预测图神经网络（GNN）训练。
- **典型场景**：
  1. 需要高质量、经过科学清洗的已知相变体系配比、晶体结构与物性数据集；
  2. 通过 OpenAPI 标准接口获取所有具有明确活化能与结晶温度的材料样品，作为监督训练集；
  3. 利用知识图谱分析元素协同掺杂模式，提取化学空间子图嵌入。
- **核心痛点**：
  - 文献中材料化学式书写不规范（如下标未统一、掺杂格式混乱）；
  - 缺乏机器可读、格式严谨的公共 API；
  - 缺乏对文献争议数据（Disputed Records）的显式标记。
- **需求优先级**：
  - P0：化学式严格归一化与规范化成分拆解；
  - P0：标准化 REST API 与批量结构化导出；
  - P1：显式标记争议数据与数据质量置信度。

### 用户画像 3：资深数据审核专家 —— 王教授 (Prof. Wang)
- **背景**：相变材料领域资深科学家，担任数据库学术顾问。
- **典型场景**：
  1. 定期进入【受控审核工作台】，审阅由自动化流水线提取的候选数据包；
  2. 比对文献 PDF 关键段落，核实模型抽取的相变温度、测试方法是否无误；
  3. 针对提取有微小瑕疵的记录，提交修正载荷（Corrected Payload）并原子晋升为正式观测；
  4. 对学术界存在重大争议的文献数据标记为 `DISPUTED` 并附注同行评议说明。
- **核心痛点**：
  - 提取数据与文献原文缺乏并排（Side-by-Side）即时对照；
  - 审核操作缺乏防并发冲突的乐观锁机制（容易被他人覆盖）。
- **需求优先级**：
  - P0：单事务原子审核与审计轨迹追溯；
  - P0：乐观并发控制（`If-Match` 弱 ETag）；
  - P1：文献原文高效并排审阅与高亮辅助。

## 3. 用户界定对系统架构与战略的决定性影响

1. **产品方向与功能取舍**：
   - **坚持**：“无证据，不入库”。所有正式物性断言必须包含 DOI 与原文片段/图表锚点；
   - **放弃**：开放域生成式闲聊机器人、脱离测定条件的简单平均值聚合。
2. **权限与访问控制模型**：
   - **匿名科研学者**：全量只读访问，可使用所有检索、横向对比、图谱探索与数据导出功能；
   - **注册研究员 (Researcher)**：可批量投喂上传文献，数据进入 `ext_*` 暂存区；
   - **领域审核专家 (Curator)**：具备候选晋升、正式记录状态流转（`VERIFIED` / `DISPUTED` / `RETRACTED`）权限；
   - **系统管理员 (Admin)**：全局配置、用户管理、审计日志追踪。
3. **数据开放与生态策略**：
   - 数据权威事实源以 OpenAPI 标准完全开放，支持学术界自由引用与科研使用；
   - 采用 Apache 2.0 开源协议，鼓励社区共同丰富相变体系知识图谱。

## 4. 关键成功衡量指标 (Success Metrics)

| 维度 | 第一轮 MVP 基线 | 第二轮目标 (Target) | 长期愿景 (Vision) |
| :--- | :--- | :--- | :--- |
| **文献对比耗时** | 单篇手工查询，比对 5 篇耗时 ~3 小时 | **看板一键对齐过滤，耗时 < 1 分钟** | 秒级自动生成多维度相变材料对比分析报告 |
| **元数据抽取准确率** | 手工正则，准确率 ~65% | **接入 Crossref/OpenAlex 权威补全，达 98%+** | 达到商业出版级元数据精准度 |
| **核心物性提取准确率** | 启发式规则/模拟，准确率 ~60% | **基于 Pydantic 严格 Schema 抽取，准确率 85%+** | 结合多模态图表识别，准确率突破 92% |
| **证据链可溯源比例** | 约 70% | **100% 正式发布记录具备完整图表与片段回溯** | 100% 支持原文边界框（Bounding Box）高亮定位 |
| **材料筛选实验周期** | 传统需盲目合成 10~20 组样品进行测试 | **通过数据看板与图谱提前收敛最优掺杂区间，减少 50% 实验试错** | 结合机器学习预测，一次性命中率 > 80% |

## 5. 阶段服务对象明确

- **第一轮 MVP（已完成）服务对象**：
  - 核心服务了**本地开发者与材料实验科学家演示体验**：跑通了单体系材料录入、文献上传解压、条件过滤对比与人工审核状态机，建立了可运行的原型基线。
- **第二轮 MVP（本期重点）服务对象**：
  - **优先服务真实科研场景下的“材料实验科学家”与“数据审核专家”**：重点解决大文件批量上传稳定性、元数据权威补全、真实大模型提取暂存、物性对比导出与审核流闭环，同时进行系统安全整改与上帝类解耦，为高频科研使用奠定高可用架构底座。
